# 坦克大战 (Tank Battle)

经典坦克大战游戏的 HTML5 实现，纯前端无需任何依赖。

## 玩法

- **⬆⬇⬅➡** 或 **WASD** 移动坦克
- **空格键** 发射子弹
- **R键** 重新开始

## 游戏规则

- 消灭所有敌方坦克即可过关
- 保护基地（底部 HQ 标志）不被摧毁
- 砖墙可被子弹摧毁，钢墙不可摧毁
- 每关敌人数量和速度会逐渐增加

## 技术

- HTML5 Canvas 渲染
- 纯 JavaScript，无框架依赖
- 可直接在浏览器中打开 `index.html` 游玩
